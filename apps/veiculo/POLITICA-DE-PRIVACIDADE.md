# Política de Privacidade — Veículo

**Última atualização:** 2026-08-11

## Resumo

O app Veículo não coleta, armazena, transmite nem compartilha nenhum dado pessoal. Todos os dados inseridos ficam armazenados exclusivamente no dispositivo do usuário.

## Dados que o app não coleta

- Nenhum dado é enviado para servidores externos
- Nenhum cadastro ou conta é necessário
- Nenhuma localização é acessada
- Nenhum dado de uso é rastreado
- Nenhuma propaganda é exibida

## Dados que ficam no dispositivo

O app armazena localmente, apenas no seu dispositivo:

- Informações dos veículos cadastrados (apelido, placa, marca/modelo, quilometragem)
- Histórico de abastecimentos (data, km, litros, valor, posto)
- Histórico de manutenções (data, km, tipo, valor, oficina)
- Lembretes configurados (tipo, descrição, alvo por km ou data)

Esses dados pertencem ao usuário. Eles podem ser exportados (backup) e restaurados a qualquer momento, e são apagados junto com o app se o usuário desinstalar.

## Backup

O recurso de backup gera um arquivo JSON que o usuário pode salvar onde preferir (Google Drive, WhatsApp, e-mail etc.). O desenvolvedor do app não tem acesso a esse arquivo.

## Compras (plano pago)

Se o usuário adquirir o plano pago, a transação é processada pela Google Play. O desenvolvedor não tem acesso a dados de pagamento. O único dado relacionado à compra armazenado pelo app é o status do plano (gratuito ou pago), salvo localmente no dispositivo.
